# 50記事目 pet-meal-bib 画像5枚 生成仕様（ChatGPTへ渡す用）

## 共通条件（5枚すべて）
- 写実的な写真調（イラスト・3DCG不可）
- 高画質・ノイズやブレのない仕上がり
- 文字要素なし（テキスト・ロゴ・透かしなし）
- ブランドロゴなし
- 読める商品ラベル・パッケージ文字なし
- コラージュ・分割構図禁止（1枚＝1シーン）
- 重要な被写体（犬・よだれかけ・人物の手）をフレーム端に寄せない。中央〜中央やや下に配置し、四辺に十分な余白を確保する
- object-fit: cover で上下左右が多少トリミングされても主要被写体が欠けない構図にする
- シニア犬との暮らしとして自然な、室内の生活感のあるシーン
- 犬種は指定しないが、落ち着いた様子のシニア犬(口周りや被毛に白髪が見える、ゆったりした動作など)であることが分かる見た目が望ましい

## 1. hero.webp（約1672×941、16:9横長）
- **シーン**：キッチンまたはリビングで、無地のよだれかけ(ブランド表示なし)を着けたシニア犬が食器の近くで落ち着いている様子
- **犬の状態・姿勢**：座っているか伏せている。食後の落ち着いた表情
- **人物**：入れない
- **商品の見せ方**：よだれかけは首元に自然に着けられている程度の見え方(柄や素材感が分かる近さ)
- **カメラアングル**：犬の目線に近いアイレベル〜やや上からのミドルショット
- **背景**：自然光の入るキッチンまたはリビングの床。生活感のある落ち着いた色調
- **光**：自然光、柔らかい昼光
- **見切れ防止**：犬とよだれかけの両方が画面中央〜やや下に収まるよう、上部に余白を多めに取る
- **入れてはいけないもの**：文字、ロゴ、読める商品パッケージ、人物、複数の犬

## 2. point-1-size.webp（約1254×1254、1:1）
- **選び方ポイント対応**：「01 サイズ(首回り)」
- **シーン**：人の手がよだれかけの首回りの留め具・紐部分を調整している様子
- **犬の状態・姿勢**：写らなくてよい
- **人物の動作**：よだれかけの首元の留め具やマジックテープ部分を手で調整する動作
- **商品の見せ方**：よだれかけの首回り部分の質感・サイズ調整機構が分かる近距離
- **カメラアングル**：斜め上からのクローズアップ
- **背景**：ぼんやりとした室内の背景
- **光**：自然光
- **見切れ防止**：手と留め具部分を画面中央に配置
- **入れてはいけないもの**：文字、ロゴ、読めるラベル

## 3. point-2-waterproof.webp（約1254×1254、1:1）
- **選び方ポイント対応**：「02 防水性」
- **シーン**：よだれかけの表面に水滴が乗っている、または人の手で軽く水をかけて防水性を確認しているような構図
- **犬の状態・姿勢**：写らなくてよい
- **人物の動作**：よだれかけの表面に指先で水滴を垂らす、または軽く触れる動作
- **商品の見せ方**：生地の表面に水滴が玉になっている様子(防水性が伝わる質感)
- **カメラアングル**：真上〜斜め上からのクローズアップ
- **背景**：床やテーブルの一部がぼんやり見える程度
- **光**：自然光、水滴が際立つ柔らかい光
- **見切れ防止**：水滴と生地の接触部分を画面中央に配置
- **入れてはいけないもの**：文字、ロゴ、読めるラベル

## 4. point-3-material.webp（約1254×1254、1:1）
- **選び方ポイント対応**：「03 素材」
- **シーン**：人の手がよだれかけの生地をつまんで質感を確認している様子
- **犬の状態・姿勢**：写らなくてよい
- **人物の動作**：生地を指でつまむ、または軽くめくって裏地を見せる動作
- **商品の見せ方**：生地の織り方や厚み、裏地の質感が分かる近距離
- **カメラアングル**：斜め上からのクローズアップ
- **背景**：床やテーブルの一部がぼんやり見える程度
- **光**：自然光、質感が分かりやすい斜め光
- **見切れ防止**：手と生地の接触点を画面中央に配置
- **入れてはいけないもの**：文字、ロゴ、読めるラベル

## 5. point-4-washing.webp（約1254×1254、1:1）
- **選び方ポイント対応**：「04 お手入れのしやすさ」
- **シーン**：洗面所またはキッチンのシンクで、よだれかけを手洗いしている、または洗濯機に入れようとしている様子
- **犬の状態・姿勢**：写らなくてよい
- **人物の動作**：よだれかけを両手で持ちシンクの水につける、または洗濯機のドラムに入れる動作
- **商品の見せ方**：よだれかけが水や洗濯機と接触している瞬間
- **カメラアングル**：やや高めの位置からの斜め見下ろし(hero/point-2とは異なる距離・角度)
- **背景**：洗面所またはキッチンのシンク周り、生活感のある清潔な空間
- **光**：室内照明＋自然光のミックス、清潔感が伝わる明るめの光
- **見切れ防止**：よだれかけとシンク/洗濯機の接点を画面中央〜やや下に配置
- **入れてはいけないもの**：文字、ロゴ、読めるラベル、洗剤ボトルのブランド表示
